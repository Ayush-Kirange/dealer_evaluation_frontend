# Cars Dealership — Full-Stack Development Capstone

## Repository Name
`dealer_evaluation_frontend`

## Project Name
**Cars Dealership — Full-Stack Web Application**

## Project Overview
The Cars Dealership project is a full-stack web application developed as part of the IBM Full-Stack Developer Capstone project on Coursera. The application represents a national car dealership network in the United States and allows users to explore dealership locations, view dealer information, and read and submit customer reviews.

The project demonstrates the implementation of frontend and backend components, REST APIs, database integration, user authentication, sentiment analysis, and deployment workflows.

## Objectives
- Build a responsive web interface for displaying car dealerships.
- Retrieve dealership information through backend APIs.
- Implement user registration, login, and logout functionality.
- Enable users to view and submit dealership reviews.
- Integrate sentiment analysis to evaluate customer feedback.
- Use Git and GitHub for version control and GitHub Actions for CI/CD.
- Practice containerization and cloud deployment.

## Technologies
- **Frontend:** React, JavaScript, HTML5, CSS3
- **Backend:** Django and supporting REST API services
- **Other backend technologies explored:** Flask and Node.js
- **Database:** SQLite and MongoDB, depending on the service
- **Version Control:** Git and GitHub
- **CI/CD:** GitHub Actions
- **Deployment technologies:** Docker, Kubernetes, and IBM Cloud Code Engine
- **API Testing:** cURL
- **Sentiment Analysis:** Review text analysis service

*Note: The technologies listed above describe the capstone's technology scope. The exact technologies used by each component depend on the supplied project files and completed tasks.*

## Main Features
1. **Dealership Listing:** Displays available dealerships and their information.
2. **State-Based Filtering:** Allows dealerships to be filtered by state.
3. **Dealer Details:** Displays information about a selected dealership.
4. **User Registration:** Provides a registration form with username, first name, last name, email, and password fields.
5. **Authentication:** Supports user login and logout.
6. **Customer Reviews:** Allows users to view existing reviews and submit new reviews.
7. **Sentiment Analysis:** Analyzes review text and returns a sentiment result.
8. **Responsive Interface:** Provides dealership information through a web-based interface.
9. **Automated Workflow:** Uses GitHub Actions to support CI/CD activities.
10. **Cloud Deployment:** Supports deploying the application to a cloud environment.
